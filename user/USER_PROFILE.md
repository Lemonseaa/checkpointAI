# User Profile

This file is the only formal preference source for LoopHarness agents.

Only the human user should edit this file. Hermes and other agents may suggest
updates in `SUGGESTED_PROFILE_NOTES.md`, but suggestions are not formal
constraints until the human copies or rewrites them here.

## Core Goals

- Build systems with compounding value instead of one-off delivery work.
- Use external workflow wheels where they are mature.
- Keep Loop Harness focused on evidence, visibility, review, and optimization control.

## Decision Principles

- Do not execute live trading, production publishing, or irreversible deployment without explicit human approval.
- Prefer conservative, explainable changes over large unexplained rewrites.
- Keep prompt optimization patch-first. Full rewrites are refactor proposals, not routine edits.
- Treat historical and shadow evidence as advisory until the user approves deployment timing.
